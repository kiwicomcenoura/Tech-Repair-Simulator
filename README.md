# 🇧🇷 Português

## 🖥️ Sobre o jogo

**Tech Repair Simulator** é um jogo de simulação de assistência técnica de computadores, desenvolvido em **Godot**, com gráficos em **2D Pixel Art** e perspectiva isométrica.

O objetivo é oferecer uma experiência de manutenção de computadores, permitindo que o jogador administre sua própria assistência técnica, diagnostique problemas, substitua componentes e desenvolva seu negócio.

Você começará com uma pequena oficina e poderá evoluir conforme realizar serviços e conquistar novos clientes.

## ⚙️ Funcionalidades

### 🔧 Manutenção de computadores
- Interação física com computadores e componentes.
- Abertura de gabinetes e remoção de parafusos.
- Substituição manual de memória RAM.
- Diagnóstico de falhas e testes de inicialização.
- Sistema de compatibilidade entre componentes.

### 💻 Componentes e equipamentos
- Processadores, placas de vídeo, memórias RAM, SSDs e outros componentes.
- Identificação individual das peças.
- Sistema de saúde, desgaste e condições.
- Componentes novos, usados e defeituosos.
- Inventário físico e armazenamento na oficina.

### 🛒 Economia e comércio
- Loja de peças integrada ao computador da oficina.
- Compras com moeda fictícia.
- Sistema de entregas de componentes.
- Marketplace de peças usadas e negociação de preços *(planejado)*.

### 🏪 Administração da oficina
- Oficina explorável em perspectiva isométrica.
- Computador administrativo com sistema operacional fictício, **TechOS**.
- Bancada interativa de manutenção.
- Sistema de salvamento do progresso.
- Gerenciamento de clientes, finanças e expansão da oficina *(planejado)*.

## 🚧 Estado do desenvolvimento

O projeto está em uma fase **pré-alfa**.

Atualmente, o foco é desenvolver e aperfeiçoar as mecânicas fundamentais, principalmente a interação física com equipamentos e a manutenção manual.

**O jogo ainda está bastante cru.** Algumas interfaces são protótipos, existem funcionalidades incompletas e muitas mecânicas ainda precisam ser implementadas.

As funcionalidades descritas podem mudar durante o desenvolvimento.

# 🇺🇸 English

## 🖥️ About the Game

**Tech Repair Simulator** is a computer repair shop simulation game developed with **Godot**, featuring **2D pixel art** graphics and an isometric perspective.

The goal is to provide a hands-on computer repair experience, allowing players to manage their own repair shop, diagnose hardware issues, replace components, and grow their business.

You'll start with a small workshop and gradually expand as you complete repair jobs and attract new customers.

## ⚙️ Features

### 🔧 Computer Repair
- Physical interaction with computers and components.
- Opening computer cases and removing screws.
- Manual RAM replacement.
- Hardware diagnostics and boot testing.
- Component compatibility system.

### 💻 Hardware and Components
- CPUs, GPUs, RAM, SSDs, and other components.
- Individually identified hardware parts.
- Component health, wear, and condition systems.
- New, used, and defective hardware.
- Physical inventory and workshop storage.

### 🛒 Economy and Trading
- Parts store integrated into the workshop computer.
- Purchases using in-game currency.
- Physical component delivery system.
- Used hardware marketplace and price negotiation *(planned)*.

### 🏪 Workshop Management
- Explorable isometric repair workshop.
- Administrative computer running a fictional operating system called **TechOS**.
- Interactive repair workbench.
- Save and load system.
- Customer management, finances, and workshop expansion *(planned)*.

## 🚧 Development Status

The project is currently in **pre-alpha**.

Development is focused on building and improving the core gameplay mechanics, especially physical hardware interaction and manual computer repair.

**The game is still very rough and unfinished.** Some interfaces are prototypes, several features are incomplete, and many mechanics have yet to be implemented.

Features and gameplay systems may change throughout development.

## 🛠️ Technologies

- **Engine:** Godot 4
- **Language:** GDScript
- **Art Style:** 2D Pixel Art
- **Perspective:** Isometric
- **Primary Platform:** Windows
